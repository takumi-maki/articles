# タイトル
チェックリストで作る、再現できる関数設計

## 概要
凝集度と結合度のチェックリストを使い、経験に関係なく再現できる関数設計の判断方法を紹介します。

## 背景
チーム内で経験差があり、レビューで「何が悪いのか」を言語化できず、再現性のある基準が必要でした。

## 問題
1つの関数が環境変数・fetch・React state に密結合し、「一言で説明できない」「外部の状態に依存している」状態でした。

## 気づき・判断
凝集度（一言で言えるか）と結合度（何を知っているか）のチェックリストで判断し、チーム間で pure function を作ることを意識しました。

## 聴講者への学び
チェックリストを使った判断方法と、pure function を作る具体例を、React + TypeScript のコードで知ることができます。

### 対象となるロール
フロントエンド／フルスタックエンジニア

### 想定レベル
初級〜中級
React と TypeScript の基本を理解しており、チーム開発でコードレビューやコーディング規約の策定に関わる方。
