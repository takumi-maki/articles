# タイトル
Lambdaで境界を作る：Composition Root実践例

## 概要
AWS Lambda では依存が Handler に集中しやすく、ドメイン層の独立性を保ちにくい課題があります。本セッションでは、Composition Root パターンで依存の組み立てを分離し、Lambda でもドメイン層を守るための設計判断を紹介します。

## 背景
Amplify で稼働中の API プロジェクトで、ドメインロジックを中心に据えた設計を目指していました。

## 問題
Handler が DynamoDB・OpenSearch などのクライアント生成を担い、技術詳細が表層に漏れ出していました。

## 気づき・判断
依存の組み立てを Composition Root に集約し、Handler はユースケースの実行のみを担当する構造に整理しました。

## 聴講者への学び
Lambda で依存の向きを制御する具体的な実装パターンと、ドメイン層を守るための設計判断を持ち帰れます。
